## How to Add Content

<Steps>
<Step title="Navigate to Content Library">
  Go to your content dashboard and click "Add Content".
  
  <Info>
  You can add content that you've uploaded or generated, or create new content from scratch.
  </Info>
</Step>

<Step title="Select Content Source">
  Choose where your content is coming from.
  
  <Tabs>
  <Tab title="Uploaded Files">
    Select from your uploaded files library
  </Tab>
  
  <Tab title="Generated Content">
    Choose from AI-generated content
  </Tab>
  
  <Tab title="Create New">
    Start with a blank canvas
  </Tab>
  
  <Tab title="External Link">
    Link to external resources
  </Tab>
  </Tabs>
</Step>

<Step title="Configure Content Details">
  Fill in the required information for your content.
  
  ```json
  {
    "title": "Introduction to Machine Learning",
    "description": "Comprehensive guide to ML basics",
    "category": "AI & Technology",
    "difficulty": "intermediate",
    "duration": "45 minutes",
    "tags": ["machine-learning", "AI", "tutorial"]
  }
  ```
  
  <Tip>
  Add detailed descriptions and accurate metadata to improve discoverability.
  </Tip>
</Step>

<Step title="Assign to Collection or Course">
  Place your content in the appropriate collection or course structure.
  
  <Check>
  Content properly organized in collections is easier for users to navigate and learn from.
  </Check>
</Step>

<Step title="Set Access and Permissions">
  Configure who can view and interact with your content.
  
  <Warning>
  Review permission settings carefully before making content public.
  </Warning>
</Step>
</Steps>

## Creating Collections

Collections help organize related content together.

<Steps>
<Step title="Create Collection">
  Click "New Collection" and provide a name and description.
</Step>

<Step title="Add Content Items">
  Drag and drop content items into your collection or use the "Add to Collection" button.
</Step>

<Step title="Order Content">
  Arrange content in the desired sequence for learners.
  
  <Note>
  Content order matters for courses and learning paths - arrange from beginner to advanced.
  </Note>
</Step>

<Step title="Configure Collection Settings">
  Set collection visibility, prerequisites, and completion requirements.
</Step>
</Steps>

### Course Structure

```
Course
├── Module 1: Introduction
│   ├── Lesson 1.1: Overview
│   ├── Lesson 1.2: Key Concepts
│   └── Quiz 1
├── Module 2: Core Topics
│   ├── Lesson 2.1: Topic A
│   ├── Lesson 2.2: Topic B
│   └── Assignment 1
└── Module 3: Advanced Topics
    ├── Lesson 3.1: Advanced Concept
    ├── Lesson 3.2: Practical Application
    └── Final Exam
```

## Content Metadata

<ParamField body="title" type="string" required>
  The title of your content. Should be clear, descriptive, and keyword-rich.
</ParamField>

<ParamField body="description" type="string" required>
  A brief summary of what the content covers. Displayed in search results and listings.
</ParamField>

<ParamField body="category" type="string" required>
  The category this content belongs to. Must be an existing category.
</ParamField>

<ParamField body="tags" type="array" default="[]">
  Array of tag strings for improved searchability and organization.
</ParamField>

<ParamField body="difficulty" type="string" default="beginner">
  Difficulty level: `beginner`, `intermediate`, or `advanced`.
</ParamField>

<ParamField body="duration" type="integer">
  Estimated time to complete in minutes.
</ParamField>

<ParamField body="prerequisites" type="array" default="[]">
  Array of content IDs that should be completed before this content.
</ParamField>

## Best Practices

<Tip>
- Use consistent naming conventions across your content
- Create logical hierarchies with collections and courses
- Set appropriate difficulty levels and prerequisites
- Add comprehensive tags for better search functionality
- Include estimated completion times
- Write clear, informative descriptions
- Review content organization regularly
</Tip>

## Troubleshooting

<AccordionGroup>
<Accordion title="Content not appearing in collection">
  - Verify the content is published
  - Check collection visibility settings
  - Ensure you have proper permissions
  - Try removing and re-adding the content
</Accordion>

<Accordion title="Unable to reorder content">
  - Make sure you're in edit mode
  - Check that you have admin or editor permissions
  - Refresh the page and try again
  - Clear browser cache if issue persists
</Accordion>

<Accordion title="Tags not working">
  - Ensure tags are properly formatted (lowercase, no spaces)
  - Check that tags exist in your tag library
  - Save content after adding tags
  - Re-index search if tags still don't appear
</Accordion>
</AccordionGroup>
