## How to Publish Content

<Steps>
<Step title="Review Content">
  Thoroughly review your content before publishing.
  
  <Warning>
  Once published, content becomes visible to users. Always preview before publishing.
  </Warning>
  
  **Pre-publish checklist:**
  - Content is complete and accurate
  - All media files load correctly
  - Links work properly
  - Metadata is complete
  - Permissions are configured
</Step>

<Step title="Configure Publishing Settings">
  Set visibility, access control, and scheduling options.
  
  ```json
  {
    "visibility": "public",
    "publish_date": "2024-03-20T10:00:00Z",
    "access_level": "all_users",
    "featured": true,
    "notifications": true
  }
  ```
  
  <Tabs>
  <Tab title="Public">
    Visible to all users and discoverable in search
  </Tab>
  
  <Tab title="Unlisted">
    Accessible via direct link but not in search results
  </Tab>
  
  <Tab title="Private">
    Only visible to specific users or groups
  </Tab>
  
  <Tab title="Draft">
    Not published, visible only to editors
  </Tab>
  </Tabs>
</Step>

<Step title="Set Distribution Channels">
  Choose where your content will appear.
  
  <AccordionGroup>
  <Accordion title="Platform Channels">
    - Main content library
    - Category pages
    - Course collections
    - Featured section
    - Search results
  </Accordion>
  
  <Accordion title="External Channels">
    - Email notifications
    - RSS feeds
    - Social media
    - Partner platforms
    - API endpoints
  </Accordion>
  </AccordionGroup>
</Step>

<Step title="Preview Before Publishing">
  Use the preview function to see how content appears to users.
  
  <Tip>
  Test your content on different devices (desktop, tablet, mobile) to ensure proper display.
  </Tip>
</Step>

<Step title="Publish">
  Click the "Publish" button to make your content live.
  
  <Check>
  You'll receive a confirmation message with a link to your published content.
  </Check>
</Step>
</Steps>

## Scheduled Publishing

Schedule content to be published automatically at a specific date and time.

### Setting a Schedule

<Steps>
<Step title="Enable Scheduling">
  Toggle "Schedule for later" in the publishing settings.
</Step>

<Step title="Set Date and Time">
  Choose when you want the content to be published.
  
  <Note>
  Times are in UTC. Your local timezone: will be converted automatically.
  </Note>
</Step>

<Step title="Configure Notifications">
  Choose whether to notify users when content is published.
</Step>

<Step title="Save Schedule">
  Save your scheduling settings. Content will publish automatically.
</Step>
</Steps>

## Access Control

Control who can view and interact with your published content.

<ParamField body="visibility" type="string" required>
  Content visibility level: `public`, `unlisted`, `private`, or `draft`.
</ParamField>

<ParamField body="access_groups" type="array" default="[]">
  Array of group IDs that have access to this content. Empty array means all users.
</ParamField>

<ParamField body="requires_enrollment" type="boolean" default="false">
  Whether users must enroll in a course to access this content.
</ParamField>

<ParamField body="payment_required" type="boolean" default="false">
  Whether payment is required to access this content.
</ParamField>

<ParamField body="geographic_restrictions" type="array" default="[]">
  Array of country codes where content is available or restricted.
</ParamField>

## Managing Published Content

### Updating Published Content

<Warning>
Changes to published content take effect immediately. Users viewing the content will see updates in real-time.
</Warning>

<Steps>
<Step title="Edit Content">
  Make necessary changes to your published content.
</Step>

<Step title="Review Changes">
  Preview updates before saving.
</Step>

<Step title="Save Updates">
  Click "Update" to apply changes to the published content.
  
  <Tip>
  Enable "Notify users of updates" to alert subscribers about significant changes.
  </Tip>
</Step>
</Steps>

### Unpublishing Content

To remove content from public view:

1. Navigate to the content settings
2. Change status from "Published" to "Draft" or "Archived"
3. Confirm the unpublish action

<Note>
Unpublishing content does not delete it. You can republish at any time.
</Note>

## Best Practices

<Tip>
- Always preview content before publishing
- Use scheduled publishing for consistent release timing
- Set appropriate access controls for sensitive content
- Monitor analytics after publishing to gauge performance
- Update content regularly to keep it fresh and relevant
- Archive outdated content rather than deleting it
- Use featured flags sparingly for high-priority content
- Test content on multiple devices before publishing
</Tip>

## Troubleshooting

<AccordionGroup>
<Accordion title="Content not appearing after publish">
  - Verify publish status is "Published" not "Draft"
  - Check visibility settings are not set to "Private"
  - Clear browser cache and refresh
  - Ensure content meets all publishing requirements
  - Check that publish date is not in the future
</Accordion>

<Accordion title="Scheduled publish didn't happen">
  - Verify the scheduled time has passed
  - Check that scheduling was properly saved
  - Confirm your account has active publishing permissions
  - Review system notifications for any errors
  - Contact support if issue persists
</Accordion>

<Accordion title="Users can't access published content">
  - Check access control settings
  - Verify user groups have proper permissions
  - Ensure enrollment requirements are met
  - Check for geographic restrictions
  - Verify content is not in "Unlisted" mode
</Accordion>

<Accordion title="Changes not appearing">
  - Clear CDN cache (if applicable)
  - Hard refresh your browser (Ctrl+Shift+R)
  - Verify changes were saved successfully
  - Check that you're viewing the correct version
  - Allow a few minutes for cache updates
</Accordion>
</AccordionGroup>
